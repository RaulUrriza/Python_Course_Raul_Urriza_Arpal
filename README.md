# Python_Course_Raul_Urriza_Arpal

## What this software is for

This software was developed with the idea of extract the phase information from the labview data before save it, show the phase difference between same point data adquisition to calculate the deformation in time and show the final result, how is propagating and with which speed.

## Installation instructions

This software was developed to works with LabView 2022. For this reason is necessary to install first python 3.9 in the computer of 64 bits and install the libraries in terminal.

    py -3.9 -m pip install numpy scipy nptdms pyyaml
